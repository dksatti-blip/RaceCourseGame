About RaceCourseGame:
1. This is a multi-user RaceCourse Game created using Unity Software
2. To play on Windows you need the following three items which are part of the RaceCourse-Windows.zip
* RaceCourse.exe
* RaceCourse_Data(Folder)
* UnityPlayer.dll
One of you is a host of the game and the other is a Client.

The Letter W moves the car forward, S backwards, WA - Left wards, WD rightwards.
