
What is new in Version 2.0:
An Oval Racecourse Strip
Max 4 Player facility
Cars can accelerate quicker
Game has three laps
Winner is displayed on all cars

Race Course:
Added a oval race course where the length of each stretch is 1Km with semi-circular bends with a 60m turn.
The road is made in version 1.0 into a 20 m-wide road to accommodate 4 cars.
A StartStopLine has been added

Race:
The max number of participants will be 4
The width of the road is 20m
The host of the game has a new StartRace Button
When the host presses the StartRace Button, countdown panels start on all cars to show 3,2,1 and Go
Cars are locked in position until Go shows up on the screen
The player has to complete three laps
There is a LapCounter Display
Winner is displayed on all Cars when he finishes the 3 Laps

Playing on Windows Machines:
2. To play on Windows, you need to unzip  the RaceCourse-Win.zip, which has the following three, apart from others
* RaceCourse.exe
* RaceCourse_Data(Folder)
* UnityPlayer.dll

About the Game:
One of you is the host of the game, and the other is a Client.
The Letter W moves the car forward, S backwards, WA - Left wards, WD rightwards.
